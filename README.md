# BMQ — Blindaje Médico Quirúrgico

Este es el repositorio frontal para la plataforma institucional y comercial de **Blindaje Médico Quirúrgico (BMQ)**.

## Arquitectura y Tecnologías
- **Core:** React + TypeScript + Vite
- **Estilos:** Tailwind CSS v4
- **Animaciones:** Framer Motion
- **Enrutamiento:** React Router DOM (v6)

## Documentación Oficial
- [Design System & Paleta Oficial](./DESIGN_SYSTEM.md): Contiene los tokens visuales y directrices estéticas para mantener la identidad sobria, premium e institucional del producto. **(Fuente de Verdad)**.
- [Reglas de Negocio](./BUSINESS_RULES.md): Documenta las decisiones operativas, de tarificación y de arquitectura de la plataforma.

## Comandos

```bash
# Instalar dependencias
npm install

# Correr en desarrollo
npm run dev

# Construir para producción
npm run build
```
